# CHAR: বাংলাদেশ সারভাইভাল

একটি মৌলিক, browser-playable 3D survival prototype—বাংলাদেশের নদীচর, বাঁশবন, গ্রাম ও জোয়ারভাটার আবহে। Three.js দিয়ে দৃশ্য ও সব চরিত্র/পরিবেশ procedural geometry থেকে তৈরি; কোনো তৃতীয় পক্ষের গেমের asset, নাম বা creature নকল করা হয়নি। UI ও পরিচিতি বাংলায়।

## চালানো

`index.html`-কে সরাসরি `file://` দিয়ে খুললে কিছু ব্রাউজারে ES module/CORS সীমাবদ্ধতা দেখা দিতে পারে। একটি static HTTP server দিয়ে চালান:

```bash
python -m http.server 8000
```

তারপর `http://localhost:8000` খুলুন। Three.js CDN থেকে লোড হয়, তাই প্রথমবার ইন্টারনেট লাগবে। Desktop-এ Chrome/Firefox/Edge এবং WebGL সমর্থিত Android browser-এ চেষ্টা করুন।

## নিয়ন্ত্রণ

- **WASD**: চলা; **Shift**: দৌড়; **মাউস**: তৃতীয়-ব্যক্তি ক্যামেরা (গেমে ক্লিক করে pointer lock); **E**: কাছের সম্পদ/পানির উৎস ব্যবহার; **বাম ক্লিক বা Space**: আঘাত।
- মোবাইলে পর্দার দিক-নির্দেশ বোতাম, **ব্যবহার**, ও **আঘাত** বোতাম।
- HUD থেকে কারুকাজ, আশ্রয় নির্মাণ, খাবার এবং সাহায্য দেখা যায়।

## বর্তমান প্রোটোটাইপে

- Procedural 3D চর, নদী/খাল, কাঁচা পথ, বাঁশবন, পুকুর/কুয়ো, মাছের ঝুড়ি, ফলগাছ, পাথর ও লোহার শিরা।
- টিন/মাটির গ্রামঘর, বাজারের ছাউনি, রিকশা, ডিঙি নৌকা, বাঁশের সেতু এবং তালগাছের দৃশ্য।
- কাঠ/বাঁশ/পাথর/লোহা/খাবার/পানি সংগ্রহ, ক্ষুধা-তৃষ্ণা-স্বাস্থ্য-শক্তি, সরঞ্জাম ও খাবার কারুকাজ, আশ্রয় ও চুলা নির্মাণ।
- দিন-রাত, কুয়াশা, আবহাওয়ার পালাবদল, রাত্রিকালীন মৌলিক শত্রু এবং বেঁচে থাকার লক্ষ্য।
- কোনো বাহ্যিক আর্ট/অডিও ফাইল নেই; চরিত্র ও শত্রু সম্পূর্ণ নিজস্ব procedural shapes।

## পরবর্তী զարգացման шаард

এটি playable vertical slice, production game биш। অনলাইন ১–৪ জন co-op/revive, сервер-authoritative world, পূর্ণ map/quest progression, Bengali NPC dialogue/voice, authored sound, advanced AI/combat, save system, Android build packaging ও performance profiling এখনও বাস্তবায়িত নয়। এগুলোর জন্য নেটওয়ার্ক/সার্ভার, art/audio content এবং platform pipeline যোগ করতে হবে।
